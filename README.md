## 详细简介
提供一个像网游里那样的通用的宠物终端;
有以下功能:
1. 记录驯服的宠物
2. 传送宠物到你当前位置
3. 传送宠物到你设置的家的位置
4. 为你的宠物重命名(这需要一级经验,是点数的一级,不会直接减少你的等级)
5. 可选择性的记录宠物数据:如果不再想记录某个宠物,可以点击TNT矿车图标予以注销,点击铁砧图标再点击熔岩桶图标可以看见注销的宠物,此时点击TNT矿车图标可以取消注销
6. 开启或者关闭友伤

---
## 关于此项目:
由于一些变故,项目提前发布,此项目仍处于bete版本,暂未做完,可能存在一些bug,请上报issue;
它只是一个辅助mod,不会改变你的世界,只会在存在时对你宠物位置进行更改,你可以放心添加或者删除;
